# About PromptlyHash

PromptlyHash is a focused Windows application for generating and checking file hashes.

Developed by **Draconequus**.

Project: [GitHub repository](https://github.com/draconequus93/PromptlyHash)

## Privacy

All hashes are calculated locally. Your selected files never leave this computer.

## Supported algorithms

- MD5
- SHA-1
- SHA-256
- SHA-384
- SHA-512

MD5 and SHA-1 are legacy algorithms included for compatibility. Prefer SHA-256 or SHA-512 for new checksums.

## Important

A matching hash confirms that the file content matches the expected checksum. It does not, by itself, prove who created or published the file.
