# Code of conduct

PromptlyHash aims to provide a welcoming, constructive environment.

## Expected behavior

- Be respectful and considerate.
- Discuss ideas and code rather than attacking people.
- Give and receive technical feedback constructively.
- Respect privacy and differing backgrounds or experience levels.
- Help keep discussions relevant and safe.

## Unacceptable behavior

Harassment, threats, discrimination, deliberate intimidation, unwanted sexual attention, publication of private information, and sustained disruption are not acceptable.

## Enforcement

Repository maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior is inappropriate.

Report repository abuse through GitHub's private reporting and moderation tools. Do not start a public discussion that exposes a target to further abuse.

This policy applies in repository issues, pull requests, discussions, and other project spaces.
